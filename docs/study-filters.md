# Study Filters

Each ordinary Study section has the same collapsible **Filters** panel for **Study Status** and **Part of Speech**, using the study level selected on Study. This includes Word List, Flashcards, Word Input, Meaning Quiz, Dictation, sentence exercises and language-specific exercises.

Cloze and Sentence Scramble now retain the filter panel even when no questions match, so users can recover by changing the filters. Filters select target words; cloze distractors continue to match the target's part of speech. The current sentence answer is reset when its filter changes.

German Form Input keeps its additional case, number, adjective-pattern, tense and person controls. Chinese pronunciation exercises retain their existing filters. Review retests stay scoped to the saved question instead of offering a new Study filter.

A shared 16px gap separates filters from the following content. Filter group headings, rows and dividers share their spacing across both language presentations.
