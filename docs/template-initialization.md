# Template adaptation

The `Code/template` review policy, editor settings, issue/PR templates and ownership pattern are retained. Branch targeting changes to main because the previous repository and dev-based plan were explicitly retired.

The project is a JavaScript application, so its initial CI runs Node syntax and behavioral tests rather than publishing a Python package. Python tooling, AI review credentials and native release automation are introduced only when the corresponding tasks need them. No old app histories or datasets are imported during initialization.
